The original booking exercise could admit overlapping stays for different guests and trusted persistence entities and client ownership assumptions. This change turns the same repository into **Sundrift**, an accommodation discovery and reservation system with guest, host and administrator journeys. It combines Java 21/Spring Boot, PostgreSQL and Next.js with 24 fictional South African stays and a sand, oat, clay and cocoa interface.

Guests search, save stays, receive server-calculated prices, reserve ten-minute holds, complete simulated checkout, revisit trips, cancel with policy-based refunds and review completed stays. Hosts manage listings, photographs and calendars; administrators review publication and context-scoped audit records. PostgreSQL exclusion constraints protect inventory, persisted idempotency protects retries, and transactional confirmation/cancellation keeps payments and availability consistent. HttpOnly sessions, CSRF and backend role/ownership checks protect mutations. Normal startup has no demo access or privileged fixtures.
